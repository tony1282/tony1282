# Proyectos

## Profesionales / Freelance

### Italian POS System

Sistema POS web desarrollado para un negocio de productos de belleza.

**Mi participación:** Desarrollo del backend y lógica de negocio.

- Desarrollo de APIs REST.
- Gestión de productos, variantes e inventario.
- Implementación de ventas, cajas, devoluciones y garantías.
- Implementación de reglas de negocio y validaciones.
- Autenticación y control de roles y permisos.

**Tecnologías utilizadas:** Python · Django · Django REST Framework · PostgreSQL · JWT

### Coffee Shop System

Aplicación para digitalizar la gestión de pedidos y pagos de una cafetería.

**Mi participación:** Desarrollo de la aplicación móvil e integración con servicios backend.

- Desarrollo de la aplicación móvil con Flutter.
- Implementación de autenticación y gestión de usuarios.
- Desarrollo del flujo de productos, carrito y pedidos.
- Integración de Mercado Pago.
- Integración y manejo de eventos de pago mediante webhooks.
- Desarrollo del dashboard móvil para la gestión de pedidos.

**Tecnologías utilizadas:** Flutter · Dart · Python · FastAPI · PostgreSQL · Mercado Pago · REST API
